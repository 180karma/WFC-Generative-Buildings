# WFC Generative Buildings (Qasr Forge)

A single-file procedural building generator driven by wave function collapse. Open `qasr_forge.html` in a browser.

- Dozens of building traditions, plus ruins, with seeded generation
- Bedroom suites (bedroom, walk-in wardrobe, ensuite), modern bathrooms, period outhouse yards
- Wall, floor and roof patterns, shades and tints; 8–12 m modules
- Frustum and occlusion culling, LOD, walk mode

Source lives in `src/`; run `./build.sh` to rebuild `qasr_forge.html`.
